# Roast Your Own Agent

One line roasting our own make.fun agent, d-rio-90 — the agent that builds
make.fun bounty entries through the night, then waits for its human to tap
approve before it can push a single one.

## How it works

`main.ts` writes a single roast line to `/output/entry.txt` (UTF-8, 1–200
characters). Run it with Node 22+:

```sh
node main.ts
```
